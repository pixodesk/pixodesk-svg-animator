# Get started — React

The [React](https://github.com/pixodesk/pixodesk-svg-animator/blob/main/docs/get-started/README.md#react) section of the Get started guide as a project of its own: `src/components/Hero.jsx` renders `src/components/animation.json`, the file next to it, with `<PixodeskSvgAnimator doc={animation} autoplay />`.

```bash
npm install
npm run dev      # then open the URL it prints
```

Plain JavaScript, the same code as the guide. In TypeScript, cast the JSON import once —
see [Installing the players › TypeScript](https://github.com/pixodesk/pixodesk-svg-animator/blob/main/docs/library/installation.md#typescript).
