In an <img> — static, unless exported On load

Inside an image the browser runs no scripts and the page cannot reach in to add the play classes, so a pre-rendered SVG is a still picture there — except the CSS flavour exported with the On load start option, which already carries px-anim-enabled px-anim-playing on its root. Same file, with and without those two classes:

exported with any other start option → static

exported with On load → animates
